# 1.0.0

- Generalized package from `wx_text_spoiler` to `wx_spoiler`.
- Added `WxSpoiler` for concealing arbitrary widgets and images with animated blur.
- Maintained `WxSpoilerText` for collapsible text with `WxText` typography styling.
- Added `WxSpoilerController` and `WxSpoilerProvider`.
- Dart 3 workspace ready and aligned with Flutter 3.24+.
